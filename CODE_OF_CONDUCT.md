# Código de conducta

Open Brinca publica lo que dijeron personas reales. Quien participa aquí, sea en un issue, en un pull request o en una discusión, se compromete a:

- tratar con respeto a las personas cuyas palabras se publican y a quienes aportan;
- discutir el contenido y no a las personas;
- no publicar datos personales de nadie que no los haya hecho públicos;
- corregir con evidencia, no con descalificaciones.

No se aceptan el acoso, los insultos, los ataques personales ni la publicación de información privada de terceros.

Brinca mantiene el repositorio y puede editar, ocultar o borrar comentarios, issues y pull requests que no cumplan con esto, y bloquear a quien insista. Para reportar una conducta, escríbele a Brinca desde [brinca.com](https://www.brinca.com).

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).
