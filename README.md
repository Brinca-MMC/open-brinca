# open-brinca

Open-Brinca es un repositorio de gestión del conocimiento sobre IA y adopción de IA, abierto al público. Lo cura y lo mantiene Brinca.

## Contenido

- [**Impacta IA Chile 2026**](eventos/impacta-ia-2026/README.md): las 16 sesiones transmitidas del evento (2 y 3 de septiembre de 2026, Fundación Chile), cada una con su resumen, la transcripción revisada con cada voz identificada y las imágenes notables con su autor.
